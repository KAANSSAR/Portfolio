# Kanishka Sarkar — Personal Portfolio

Personal portfolio website built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

🌐 **Live site**: coming soon

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 15 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Animations | Framer Motion 11 |
| Email | EmailJS |
| Fonts | Playfair Display · DM Sans · DM Mono |
| Deployment | Vercel |

## Sections

- **Hero** — Typing animation, parallax lettermark, cinematic name reveal
- **About** — Animated stat counters, skill tags
- **Experience** — Scroll-driven timeline with gold line draw
- **Projects** — 3D tilt cards, GitHub links
- **Life** — Masonry photo gallery with category filters
- **Contact** — EmailJS contact form + resume download

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

Deployed on Vercel. Push to `main` to trigger a redeploy.

```bash
git add .
git commit -m "your message"
git push
```
